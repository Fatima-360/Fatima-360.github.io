# UX Writing Case Study: EuroFlow Expense App

In Fintech, the goal of UX writing is to build trust and reduce "financial anxiety". This case study breaks down the microcopy decisions made for the EuroFlow User Guide.

### 1. Progressive Disclosure
Instead of overwhelming the user with every detail of tax law, I used **Action-Oriented Steps**.
* **Before:** "Users should initiate the application to begin the process of logging their expenditures."
* **After (UX Optimized):** "Open the **EuroFlow App**".

### 2. Clarity Over Cleverness
Financial users need to feel secure. I avoided "cute" language in favor of standard financial terms that users already recognize.
* **Feature Title:** I chose **"Expenses > New Entry"** because it mirrors standard accounting logic, making the app feel familiar.

### 3. Error Prevention (The "Troubleshooting" Layer)
I designed the troubleshooting section to be "just-in-time" information. By specifying **file formats (JPG/PNG)** and **size limits (5MB)**, I prevent the user from experiencing a "submission failed" error before it happens.

---
**Methodology:** These decisions were made using **Task Analysis** to ensure that even a non-technical user can complete a complex VAT reconciliation without external support.
