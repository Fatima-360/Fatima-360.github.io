# Fintech & SaaS Technical Glossary

| Category | Term | Definition |
| :--- | :--- | :--- |
| **Compliance** | **AML** | Anti-Money Laundering; legal frameworks used to prevent the generation of income through illegal activities. |
| **Compliance** | **KYC** | Know Your Customer; the mandatory process of identifying and verifying a client's identity. |
| **Compliance** | **VIES** | VAT Information Exchange System; an EU search engine for verifying the validity of VAT numbers. |
| **Finance** | **Reconciliation** | The process of ensuring that two sets of records (usually the bank and the ledger) match. |
| **Technology** | **API** | Application Programming Interface; a set of rules that allow two software programs to communicate with each other. |
| **Technology** | **SaaS** | Software as a Service; a model where software is hosted centrally and accessed via the internet. |
| **Documentation** | **Docs-as-Code** | An approach where documentation is treated like code, using version control (Git) and Markdown. |
