Overview

This documentation guides users through account creation, identity verification, and security practices for the FinCore Wallet platform.

Account Creation

  1. Download the FinCore app.
  2. Enter your email and phone number.
  3. Create a secure password.
  4. Verify your email via OTP.

KYC Verification

  • Upload government-issued ID.
  • Complete selfie verification.
  • Submit proof of address (if required).

Common Errors

  • ID Rejected: Ensure image is clear and not cropped.
  • OTP Expired: Request a new verification code.
  • Verification Delayed: Review may take up to 24 hours.

Security Best Practices

  • Enable two-factor authentication.
  • Never share OTP codes.
  • Log out from shared devices.
